# 乘乘熱氣球｜九九乘法冒險嘉年華

給小朋友背熟九九乘法表的網頁小遊戲，主題是熱氣球嘉年華。全部程式都在一個 `index.html` 裡，不需要安裝或編譯。

## 功能

- **主視覺是鹿野高台的大草原**：整個畫面後面固定著一片手繪 SVG 的山坡草地 ——
  上面是淡藍天空，下面四層起伏的草坡，天上還飄著六顆遠方的小熱氣球（各自慢慢上下漂）。
  `body` 背景設成透明，草原才看得到
- **明亮淡彩配色**：主色霧感灰藍 `#7FA0B6`、底色淡奶油黃 `#FDFAF0`、輔色燕麥米 `#E0D4C2`、
  點綴淡鼠尾草綠 `#AEBDA4`；比前一版再亮一階，但沒有變鮮豔。大面積填色另外用提亮一階的淺色版。
  視覺語彙是**剪紙拼貼 + 絹印**：卡片沒有外框線，邊緣是 SVG 位移濾鏡做出來的手撕邊，
  底下墊一層偏移的燕麥米疊印；全站覆蓋一層紙張顆粒；標題「乘乘熱氣球」用偏移 4px 的灰藍 multiply 做套色錯位。
  **畫面固定白天模式**，不會跟著手機或電腦的深色模式變暗（要暗版的話在 `<html>` 加 `data-theme="dark"`）
- **慶典三角旗**：六色輪播、方旗和三角旗交錯、繩結上還有小圓球，比前一版更有嘉年華的感覺
- **主視覺 icon**：一顆寫著 **9×9** 的熱氣球，用的就是全站同一套顏色。
  分頁上的小圖示直接畫成 SVG 寫進 `data:` URI 掛在 `<link rel="icon">`，不用外部檔案，單檔離線也看得到；
  另有 `<meta name="theme-color">` 讓手機瀏覽器的上緣跟著天空色。
  **加到主畫面**的圖示 iOS 只吃 PNG，所以另外附了 `icon-180.png`（apple-touch-icon）和
  `icon-192.png` / `icon-512.png` + `manifest.webmanifest`（Android 用）。
  四張圖都是從 `icon.svg` 這張原稿輸出的，改圖只要改 `icon.svg` 再重出一次。
  加到主畫面後會用**獨立視窗**開啟（沒有網址列），跟一般 app 一樣
- **首頁是一片熱氣球**：六個玩法六顆球，慢慢上下漂浮（節奏各自錯開），
  手機兩個一排、平板和電腦三個一排，填滿畫面。
  氣球是**手繪 SVG**：球身上半部用貝茲近似正圓（0.5523 係數）、下半部收成短頸，
  加裙帶、細網索和小藤籃；布面有六種花紋（直條／格紋／鋸齒／波浪／圓點／葉形）。
  遊戲名稱做成小標籤貼在球的右上角、左上右下傾斜，玩法符號直接印在球身上。
  **順序照難易排**：前三顆是入門的「乘法翻翻樂、這是幾乘幾？、尋寶遊戲」，
  標籤前面有 🔰 記號（手繪的若葉盾牌，不是 emoji）、整組用**淡鼠尾草綠**；
  後三顆是「配對消消樂、蛇蛇彩虹路、乘法實戰家」，整組用**霧感灰藍**
- **說明小幫手**：每個畫面右下角都有一隻**小熊坐著小熱氣球**在旁邊隨機漂浮，寫著「不會玩按我」，
  點一下就叫出「怎麼玩？」的說明；每個畫面上方也有一條小提示；第一次建立玩家時會自動跳出教學
- **訪客模式**：入口頁可以按「先玩玩看就好」，不用名字、不用挑頭貼就能玩，
  首頁會掛一條提醒「金幣和貼紙不會留下來」，旁邊有「取名字」隨時轉成正式玩家（進度會接過去）。
  訪客模式下 `save()` 直接 return，不寫 localStorage 也不同步雲端
- **全站標注音**：整個畫面的中文都標了注音，右上角的「ㄅ」按鈕可以隨時開關（預設是開的）。
  做法不是自己排版，而是換成**源泉注音圓體**（`BpmfGenSenRounded`）—— 注音是直接畫在每個字裡面的，
  所以只要換 `font-family` 就有，不用在 HTML 裡加任何標記。漢字會變寬 1.5 倍，
  所以不能換行的地方（大標題、氣球標籤、攤位屋簷）在開注音時會自動縮小一級。
  數字和英文還是走原本的 Fredoka（`unicode-range` 限定只有漢字用注音字型）。
  **多音字**用注音 IVS 處理：在字後面補一個看不見的「異體字選擇子」（U+E01E0~5）去挑正確的讀音，
  例如「不會」的「不」要唸 ㄅㄨˊ 而不是字型預設的 ㄅㄨˋ。
  哪些字要補、補哪一個，是 `make-font.py` 拿 `zhuyin.txt` 跟字型對出來的（目前 3 個字、12 個詞）
- **全站不用 emoji**：介面符號全部是手繪的 icon 插畫風 SVG（金幣、星星、愛心、旗子、放大鏡、
  方向鍵、獎盃……）。文字裡寫的 🔰 也會被 `mk()` 換成手繪的若葉盾牌 SVG。
  只有收藏用的 40 張貼紙和尋寶場景、數數物件還是手繪 SVG 插畫
- **這是幾乘幾？** 🍡🔰（🔰 三顆的第二顆）：還不會乘法的第一站。畫面畫出「幾排、每排幾個」（🍡🍡🍡🍡🍡 四排），
  問「這是幾乘幾呢？」，兩個格子標著**「每排幾個」×「有幾排」**，點數字填進去，
  答對就唸出 **五、四、二十**（國字，語速和口訣、翻翻樂一致）並顯示口訣「五四二十」。
  **順序照課本**（被乘數 × 乘數＝每排幾個 × 有幾排）：4 排、每排 5 個只能寫 5 × 4，填成 4 × 5 會提示
  「4 × 5 是『每排 4 個、有 5 排』喔，這裡每排 5 個，要寫 5 × 4」（只是順序反了不扣熟練度）。
  前三題是小數字，後面才到 9；
  🔍 提示會先幫每一排編號教他怎麼數，再按一次才說答案。一回 8 題
- **乘法翻翻樂** 🔰：選一張乘法表後是 9 張蓋著的卡，點一下翻面看答案並同時唸出口訣。
  有「全部翻開 / 全部蓋起來 / 自動播放」。不計分，也不影響熟練度
- **乘法實戰家**：每答完一題（答對或答錯）都會**把算式唸出來**，2×2 就唸「二二得四」。
  原本的「練習闖關」和「限時挑戰」合併成一個入口。進去最上面是
  **比快挑戰（60 秒）**，下面是 12 關**全部直接可以玩、不用解鎖**。
  第 1~8 關是 2~9 的乘法，第 9~12 關是混合挑戰 ×2、弱點挑戰、👑 大魔王（15 題）。
  上方可以切換「自己打數字 / 選答案」；每關 10 題，第一次就答對八成即過關，答錯的題目同一回合會再出現一次。
  卡片上會顯示星星和這張乘法表的熟練度小綠點。
  首次通關送 1 枚金幣（全對再加 1 枚），**每天最多領 2 枚**；
  重玩通關也有 1 枚，每天最多 1 枚。轉一次扭蛋要 **2 枚金幣**（原本 1 枚），金幣不會一下就滿出來
- **配對消消樂** 🔰（簡單那一級）：選完難度就直接進遊戲（原本的「找不同」已經拿掉）。
  牌面上都是算式，**答案一樣的兩張配成一對**（說明舉的例子是 4×1 和 2×2 都是 4），
  配對成功會把兩句口訣都唸一次，**每一組亮不同的顏色**（八組八色），一眼就看得出哪兩張是一對。每一局**一半是「不同寫法」的配對**（12 = 2×6 = 3×4），
  一半是交換律（3×4 / 4×3），兩種規律都練得到；**每一局都保證至少有一組是「寫法完全不同」的**
  （像 24 = 3×8 = 4×6），不會整局都只是把算式倒過來寫。同一局裡的答案不會重複，所以不會有配錯組的問題。
  三個難度：🔰 簡單（4 組・乘數 2~6）、普通（6 組・2~9）、挑戰（8 組・2~9）
- **尋寶遊戲（找數字）** 🔰：像 Mystery Numbers 那種「找數字」的找找看遊戲。
  選 2 的乘法，畫面會畫出一個完整的卡通場景（小房間、小公園、海邊、廚房、外太空、恐龍島、下雪天、夜市），
  2、4、6……18 這九個答案就**用該表面的顏色**寫在場景上 —— 牆上、窗玻璃、棉被、地毯、樹冠、海浪、磁磚、火山……
  半透明、歪斜、還會被前面的東西擋住一半，另外再混 4~6 個不是答案的數字。
  題目**隨機出**（不照 1、2、3 的順序），找到正確答案點它一下，數字會被圈起來並唸出口訣。
  九個都找到就收進**畫廊**。找錯會提示（第三次直接指出答案），**提示鈕就放在題目旁邊**
- **場景是怎麼來的**：全部是寫在 `index.html` 裡的**手繪 SVG**（沒有外部圖片 —— 網路上的場景圖有版權問題，
  而且這個遊戲要能單檔離線執行、CSP 也擋住了外連圖片）。
  每個場景自己帶著「可以藏數字的位置 + 那個表面的顏色」和「道具擺放點」，
  emoji 道具會擺在床上、桌上、地毯上、沙灘上，位置和數量每張都隨機，所以同一個場景也不會長得一樣
- **畫廊**：完成的畫都收在這裡（答案圈著，像破關後的畫面），點開可以看大圖。
  存檔只記「乘法表 + 場景 + 亂數種子 + 日期」，畫面再用種子重算，所以每張畫永遠長得一模一樣
- **蛇蛇彩虹路**：乘法版貪食蛇，蛇本身就是一條彩虹。上面出一題，盤面上的數字都寫在**蘋果**上
  （一顆是正確答案，其他是干擾；蘋果是 CSS 裡的手繪 SVG，數字大小會跟著格子縮放），
  控制蛇去吃正確的那一顆，吃對就長大一節。
  **蛇的顏色是固定的**：紅色永遠是頭，往後照紅橙黃綠藍靛紫排下去，超過七節就再循環一次。
  吃滿 7 個完成一條彩虹，**吃到 14 個（兩條彩虹）就直接放煙火過關**，拿三顆星。
  三個難度，一次只加一個負擔：
  🔰 散步（照順序出題＋點一下走一格，5 顆心、9×9）→
  慢跑（照順序＋自動前進 850ms，4 顆心、11×11）→
  衝刺（隨機出題＋自動前進 600ms，每條彩虹加速到最快 450ms，3 顆心、11×11）。
  對小孩友善的規則：撞牆會從另一邊鑽出來、打結只會縮短不會結束、吃錯只扣一顆愛心且題目保留讓他再算一次。
  操控：**直接點蛇頭前面那一格就會轉過去**（盤面四邊是接起來的，會自己挑近路），
  也可以滑動盤面、或用下面的方向鍵（可以隱藏），電腦支援方向鍵／WASD／空白鍵暫停
- **比快挑戰**：併在「乘法實戰家」裡，60 秒內盡量答對，記錄最佳成績。
  時間條一開始就是全滿的，開始後才往下減
- **挑戰者**：可以建立多位挑戰者（最多 6 位），各自有名字和熱氣球頭貼（6 顆不同花紋的球）；星星、金幣、貼紙、熟練度和每日任務都分開記錄，隨時可以切換
- **今天的攤子（每日任務）**：三個祭典攤販**各自分離，固定在畫面最下方**，站在草坡上，
  直式橫式都是三個一排（寬度同時受螢幕寬和螢幕高限制，橫擺時不會吃掉半個畫面）。
  一個攤位就是一種難度：**初級任務 / 中級任務 / 超級任務**，
  名字寫在攤位的**屋簷**上，說明和進度寫在攤位的**桌子**上，點一下才展開那一攤的三個任務。
  任務範圍跟著難度限制：**初級只出 🔰 三個遊戲做得到的任務**，
  **超級只出配對消消樂、蛇蛇彩虹路、乘法實戰家才做得到的任務**，中級則不限。
  每完成一個任務可領 1 枚金幣，三個都完成再加 1 / 1 / 2 枚。
  **有金幣可以領的時候，那個攤位右上角會掛一個跳動的小紅驚嘆號**（手繪 SVG，不是 emoji）
- **我的轉蛋機**：做成一台漂浮、微微發光的手繪轉蛋機，**固定在畫面右上角**，點一下就打開。
  40 種貼紙（普通／稀有／閃亮），不重複抽取。**一次要 2 枚金幣**，
  金幣數旁邊、按鈕上、下面那行提示都會寫出來，金幣不夠時按鈕會變灰並顯示還差幾枚
- 答對動畫、彩紙、音效、連擊計數
- **說明文字全部改寫成 7 歲小孩聽得懂的短句**（例如「這個遊戲怎麼玩」→「怎麼玩？」）。
  首頁的「怎麼玩？」只有四句：初學乘法先玩 🔰 → 熟悉以後再玩其他遊戲，答對有星星 →
  完成攤子任務可以拿金幣 → 金幣可以玩轉蛋，有 40 種等你蒐集
- **口訣照畫面上的順序唸**：卡片寫 8×1 就唸「八一得八」，不會自己調成「一八得八」；
  題目寫 9×3 就唸「九三二十七」

## 注音字型

用的是 ButTaiwan 的**源泉注音圓體**（`BpmfGenSenRounded`，SIL OFL 1.1），
授權和著作權聲明放在 `fonts/OFL.txt`、`fonts/NOTICE.txt`。

原始字型一個字重就有 8 MB，所以 repo 裡放的是**切過子集的版本**
（`fonts/bpmf-gensen-r.woff2`，686 字、約 144 KB），只留遊戲裡真的會出現的字。
不在子集裡的字（例如玩家自己打的名字）會掉回原本的粉圓，沒有注音但不會破版。

### 改了 `zhuyin.txt` 之後怎麼重新產生

`zhuyin.txt` 現在只拿來「挑讀音」——注音長什麼樣子是字型決定的，
這張表只負責指出「哪些字的預設讀音不對」。改完要跑：

```sh
pip install fonttools brotli
# 到 https://github.com/ButTaiwan/bpmfvs/releases 下載 BpmfGenSenRounded.zip 解開
python3 make-font.py ~/Downloads/BpmfGenSenRounded-R.ttf
```

它會重新對照、把選擇子表寫進 `index.html` 的 `ZY-TABLE` 區塊，並重新輸出 woff2。
對不上的地方會印出來（目前只有「什」——ㄕㄜˊ 這個音字型沒有，所以「什麼」的「什」不標注音）。

## 執行

直接用瀏覽器打開 `index.html` 即可。

部署到 GitHub Pages：推到 repo 後，在 Settings → Pages 選擇從 `main` 分支根目錄發布。

遊戲本體全部在 `index.html` 裡；根目錄另外的 `icon.svg`、`icon-180/192/512.png`、`manifest.webmanifest`
只是「加到主畫面」用的圖示，拿掉也不影響遊戲。

重出圖示（改完 `icon.svg` 之後）：

```sh
cd <repo 根目錄>
for n in 180 192 512; do
  printf '<!doctype html><meta charset=utf-8><style>html,body{margin:0;width:%dpx;height:%dpx;overflow:hidden;background:#FDFAF0}img{display:block;width:%dpx;height:%dpx}</style><img src="icon.svg">' $n $n $n $n > _r.html
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
    --hide-scrollbars --force-device-scale-factor=1 --virtual-time-budget=2500 \
    --window-size=$n,$n --screenshot=icon-$n.png "file://$PWD/_r.html"
done
rm _r.html
```

（`_r.html` 要跟 `icon.svg` 放在同一層，`<img>` 才找得到圖。）

## 進度儲存

所有挑戰者的進度存在瀏覽器的 `localStorage`（key：`mul99-adventure-v1`），換瀏覽器或清除資料會重來。
舊版（還沒有挑戰者功能）的存檔會自動變成第一位挑戰者「挑戰者 1」，進度不會不見。

讀取存檔時一律做白名單驗證（頭貼、貼紙 id、題目鍵、日期格式、關卡編號、數值上下限），
不合法的欄位會被丟掉或換成預設值 —— 同一個網域底下的其他頁面也能寫 `localStorage`，
所以存檔一律當成不可信的輸入處理。畫面上顯示的名字另外做 HTML 跳脫。
在 claude.ai 的 Artifact 環境中，會另外同步到帳號；一般網頁環境會自動略過這部分。
