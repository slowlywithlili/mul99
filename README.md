# 九九乘法大冒險

給小朋友背熟九九乘法表的網頁小遊戲。全部程式都在一個 `index.html` 裡，不需要安裝或編譯。

## 功能

- **練習**：選 2–9 的乘法表或綜合挑戰，可選「自己打數字」或「選答案」；答錯的題目同一回合會再出現一次
- **闖關**：12 關，前 8 關是 2–9 的乘法，之後是混合、弱點挑戰和大魔王（15 題）。
  每關 10 題，第一次就答對八成即過關，過一關解鎖下一關。
  首次通關送 1 枚扭蛋幣（全對再加 1 枚）；重玩通關也有 1 枚，但每天最多 2 枚
- **複習**：翻牌模式，選一張乘法表後是 9 張蓋著的卡，點一下翻面看答案並同時唸出口訣。
  有「全部翻開 / 全部蓋起來 / 自動播放」。複習不計分，也不影響熟練度
- **限時挑戰**：60 秒內盡量答對，記錄最佳成績
- **九九表**：點格子看算式與口訣（支援語音朗讀），顏色顯示熟練度
- **挑戰者**：可以建立多位挑戰者（最多 6 位），各自有名字和頭貼；星星、扭蛋幣、貼紙、熟練度和每日任務都分開記錄，隨時可以切換
- **每日任務**：分成初階 🌱 / 中階 ⚡ / 高階 🔥 三個難度，每個難度每天 3 個新任務。
  練習的進度三個難度共用（答對題數、連續答對等），所以會先完成初階，再往上挑戰。
  每完成一個任務可領 1 枚扭蛋幣，該難度三個都完成再加 1 / 1 / 2 枚
- **扭蛋貼紙簿**：40 張貼紙（普通／稀有／閃亮），不重複抽取
- 答對動畫、彩紙、音效、連擊計數；綜合挑戰會多出還不熟的題目

## 執行

直接用瀏覽器打開 `index.html` 即可。

部署到 GitHub Pages：推到 repo 後，在 Settings → Pages 選擇從 `main` 分支根目錄發布。

## 進度儲存

所有挑戰者的進度存在瀏覽器的 `localStorage`（key：`mul99-adventure-v1`），換瀏覽器或清除資料會重來。
舊版（還沒有挑戰者功能）的存檔會自動變成第一位挑戰者「挑戰者 1」，進度不會不見。

讀取存檔時一律做白名單驗證（頭貼、貼紙 id、題目鍵、日期格式、關卡編號、數值上下限），
不合法的欄位會被丟掉或換成預設值 —— 同一個網域底下的其他頁面也能寫 `localStorage`，
所以存檔一律當成不可信的輸入處理。畫面上顯示的名字另外做 HTML 跳脫。
在 claude.ai 的 Artifact 環境中，會另外同步到帳號；一般網頁環境會自動略過這部分。
