# 九九乘法大冒險

給小朋友背熟九九乘法表的網頁小遊戲。全部程式都在一個 `index.html` 裡，不需要安裝或編譯。

## 功能

- **莫蘭迪配色**：整個遊戲是一套低彩度的柔和色票 —— 暖砂灰的底、米白的卡片、暖灰褐的外框，
  主色是芥黃／藕粉／霧綠／灰紫／霧藍。彩虹、配對卡、扭蛋球、答案選項、貼紙主題都跟著調成同一個色系，
  emoji 另外降到 80% 彩度（貼紙留 90%，它是獎勵）、尋寶的場景整張降到 86%（連同藏起來的數字一起，所以保護色還是成立）。
  深色模式是同一套的暗版（暖灰褐的夜色，不是藍黑）
- **首頁是一排熱氣球 🎈**：每個玩法一顆不同顏色的熱氣球，會慢慢上下漂浮（節奏各自錯開）。
  氣球是**手繪 SVG**（和尋寶場景一樣寫在 `index.html` 裡）：六片布幅從頂端收到氣球口、
  受光面和暗面、燃燒器、四條吊索和藤籃紋路，顏色用 CSS 變數帶進去，深色模式也照樣好看。
  吊籃上掛著小標籤：**[認識乘法]** 是先學會乘法在幹嘛的（這是幾乘幾？、複習翻翻樂），排在最上面；
  其他都是 **[乘法遊戲]**
- **說明小幫手 🦉**：右上角的 ❓ 隨時可以叫出「這一頁怎麼玩」的圖文說明（每個畫面內容不同），
  每個畫面上方也有一條小提示；第一次建立挑戰者時會自動跳出教學
- **這是幾乘幾？🍡**（首頁第一顆）：還不會乘法的第一站。畫面畫出「幾排、每排幾個」（🍡🍡🍡🍡 三排），
  問「這是幾乘幾呢？」，兩個格子標著**「有幾排」×「每排幾個」**，點數字填進去，
  答對就唸出 **三、四、十二**（國字，語速和口訣、翻翻樂一致）並顯示口訣「三四十二」。
  **順序要對**：3 排、每排 5 個只能寫 3 × 5，填成 5 × 3 會提示
  「5 × 3 是『5 排、每排 3 個』喔，這裡是 3 排，要寫 3 × 5」（只是順序反了不扣熟練度）。
  前三題是小數字，後面才到 9；
  🔍 提示會先幫每一排編號教他怎麼數，再按一次才說答案。一回 8 題
- **複習翻翻樂**：選一張乘法表後是 9 張蓋著的卡，點一下翻面看答案並同時唸出口訣。
  有「全部翻開 / 全部蓋起來 / 自動播放」。不計分，也不影響熟練度
- **練習闖關**：練習和闖關合併成一個模式，12 關**全部直接可以玩、不用解鎖**。
  第 1~8 關是 2~9 的乘法，第 9~12 關是混合挑戰 ×2、弱點挑戰、👑 大魔王（15 題）。
  上方可以切換「自己打數字 / 選答案」；每關 10 題，第一次就答對八成即過關，答錯的題目同一回合會再出現一次。
  卡片上會顯示星星和這張乘法表的熟練度小綠點。
  首次通關送 1 枚扭蛋幣（全對再加 1 枚），**每天最多領 4 枚**；
  重玩通關也有 1 枚，每天最多 2 枚 —— 關卡雖然全開，一天最多還是只能從闖關拿到 6 枚，貼紙不會一下就集滿
- **配對消消樂 🧩**：兩種玩法。
  **👯 找一樣**：牌面上都是算式，**答案一樣的兩張配成一對**（4×4 和 8×2 都是 16），
  配對成功會把兩句口訣都唸一次，**每一組亮不同的顏色**（八組八色），一眼就看得出哪兩張是一對。每一局**一半是「不同寫法」的配對**（12 = 2×6 = 3×4），
  一半是交換律（3×4 / 4×3），兩種規律都練得到；同一局裡的答案不會重複，所以不會有配錯組的問題。
  **🔍 找不同**：每張卡有兩個算式，只有一張的兩邊答案不一樣，把它找出來；
  點錯的卡會直接顯示「＝」告訴他那兩個其實一樣。
  三個難度：🌱 簡單（4 組／3 張・乘數 2~6）、⚡ 普通（6 組／4 張・2~9）、🔥 挑戰（8 組／4 張・2~9）
- **尋寶（找數字）**：像 Mystery Numbers 那種「找數字」的找找看遊戲。
  選 2 的乘法，畫面會畫出一個完整的卡通場景（小房間、小公園、海邊、廚房、外太空、恐龍島、下雪天、夜市），
  2、4、6……18 這九個答案就**用該表面的顏色**寫在場景上 —— 牆上、窗玻璃、棉被、地毯、樹冠、海浪、磁磚、火山……
  半透明、歪斜、還會被前面的東西擋住一半，另外再混 4~6 個不是答案的數字。
  題目**隨機出**（不照 1、2、3 的順序），找到正確答案點它一下，數字會被圈起來並唸出口訣。
  九個都找到就收進**畫廊**。找錯會提示（第三次直接指出答案），也有 🔍 提示鈕
- **場景是怎麼來的**：全部是寫在 `index.html` 裡的**手繪 SVG**（沒有外部圖片 —— 網路上的場景圖有版權問題，
  而且這個遊戲要能單檔離線執行、CSP 也擋住了外連圖片）。
  每個場景自己帶著「可以藏數字的位置 + 那個表面的顏色」和「道具擺放點」，
  emoji 道具會擺在床上、桌上、地毯上、沙灘上，位置和數量每張都隨機，所以同一個場景也不會長得一樣
- **畫廊**：完成的畫都收在這裡（答案圈著，像破關後的畫面），點開可以看大圖。
  存檔只記「乘法表 + 場景 + 亂數種子 + 日期」，畫面再用種子重算，所以每張畫永遠長得一模一樣
- **蛇蛇彩虹路 🍎**：乘法版貪食蛇。上面出一題，盤面上的數字都寫在**蘋果**上
  （一顆是正確答案，其他是干擾；蘋果是 CSS 裡的手繪 SVG，數字大小會跟著格子縮放），
  控制蛇去吃正確的那一顆。吃對就長大一節，而且**整條蛇的彩虹色往前轉一格**（紅橙黃綠藍靛紫），
  吃滿 7 個就完成一條彩虹 🌈，三條彩虹拿三顆星。
  四個難度，一次只加一個負擔：
  🌱 散步（照順序出題＋按一下走一格，❤️5、9×9）→
  ⚡ 慢跑（照順序＋自動前進 850ms，❤️4、11×11）→
  🔥 衝刺（隨機出題＋自動前進 600ms，每條彩虹加速到最快 450ms，❤️3）→
  👑 閃電（隨機＋450→300ms、干擾 5 個、13×13，彩虹後會冒出 🪨 石頭）。
  對小孩友善的規則：撞牆會從另一邊鑽出來、打結只會縮短不會結束、吃錯只扣一顆愛心且題目保留讓他再算一次。
  操控：盤面可以滑動，下面也有方向鍵（可以隱藏），電腦支援方向鍵／WASD／空白鍵暫停
- **限時挑戰**：60 秒內盡量答對，記錄最佳成績
- **挑戰者**：可以建立多位挑戰者（最多 6 位），各自有名字和頭貼；星星、扭蛋幣、貼紙、熟練度和每日任務都分開記錄，隨時可以切換
- **每日任務**：分成初階 🌱 / 中階 ⚡ / 高階 🔥 三個難度，每個難度每天 3 個新任務
  （包含「玩一回認識乘法」🍡 和「完成幾回配對消消樂」🧩）。
  練習的進度三個難度共用（答對題數、連續答對等），所以會先完成初階，再往上挑戰。
  每完成一個任務可領 1 枚扭蛋幣，該難度三個都完成再加 1 / 1 / 2 枚
- **扭蛋貼紙簿**：40 張貼紙（普通／稀有／閃亮），不重複抽取
- 答對動畫、彩紙、音效、連擊計數
- **口訣照畫面上的順序唸**：卡片寫 8×1 就唸「八一得八」，不會自己調成「一八得八」；
  題目寫 9×3 就唸「九三二十七」

## 執行

直接用瀏覽器打開 `index.html` 即可。

部署到 GitHub Pages：推到 repo 後，在 Settings → Pages 選擇從 `main` 分支根目錄發布。

## 進度儲存

所有挑戰者的進度存在瀏覽器的 `localStorage`（key：`mul99-adventure-v1`），換瀏覽器或清除資料會重來。
舊版（還沒有挑戰者功能）的存檔會自動變成第一位挑戰者「挑戰者 1」，進度不會不見。

讀取存檔時一律做白名單驗證（頭貼、貼紙 id、題目鍵、日期格式、關卡編號、數值上下限），
不合法的欄位會被丟掉或換成預設值 —— 同一個網域底下的其他頁面也能寫 `localStorage`，
所以存檔一律當成不可信的輸入處理。畫面上顯示的名字另外做 HTML 跳脫。
在 claude.ai 的 Artifact 環境中，會另外同步到帳號；一般網頁環境會自動略過這部分。
